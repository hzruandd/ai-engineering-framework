# 正式评审摘要入口

请基于 `tzh-review` Skill 的正式评审结果生成管理层摘要或格式化报告。

用户原始输入：
$ARGUMENTS

## 强制边界

1. `tzh-review` 是停智慧正式质量裁决的唯一事实源。
2. 本 Command 不得重新评分、重新分级或重新裁决。
3. 不得降低 P0/P1 风险等级。
4. 不得删除 Unknown、NOT_EXECUTED、未验证项或工具失败说明。
5. 不得把“不通过”改写为“有条件通过”或“通过”。
6. 不得把“生成了测试代码”写成“测试已执行通过”。

## 允许做的事

- 将 `tzh-review` 的结论整理为管理层摘要。
- 按报告模板做格式化。
- 汇总风险矩阵、Unknowns、行动项和上线条件。
- 生成对外沟通版本，但必须保留原始裁决。

## 输出要求

如果没有可引用的 `tzh-review` 正式结果，必须先提示执行 `/tzh-review tapd=<TAPD> output=full-report`，不得自行生成正式放行结论。
