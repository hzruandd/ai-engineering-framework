# 代码修改报告生成器

> **使用场景**：提交代码前、Code Review前、版本发布前
> **目标**：快速了解本次改动的范围、影响和风险

---

## 📋 任务说明

请执行以下步骤，生成详细的代码修改报告：

### 步骤1：获取分支差异信息

1. 获取当前分支名称
   ```bash
   git branch --show-current
   ```

2. 对比当前分支与master分支的差异
   ```bash
   git diff master...HEAD --stat
   git diff master...HEAD --name-status
   ```

3. 获取提交历史
   ```bash
   git log master..HEAD --oneline --graph
   ```

### 步骤2：分析代码变更

阅读实际的代码变更内容：
```bash
git diff master...HEAD
```

对以下内容进行分析：
- 新增的文件和类
- 修改的文件和方法
- 删除的文件和代码
- 数据库schema变更（SQL文件、Entity字段）
- 配置文件变更（bootstrap.yml、application.yml）
- POM依赖变更

### 步骤3：生成修改报告
