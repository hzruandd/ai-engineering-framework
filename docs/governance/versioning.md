# Versioning And Deprecation Policy

Version: 1.0.0
Updated: 2026-07-10

## Scope

Applies to core Skills, Commands, Workflow, Gates, Rules, Specs, project templates, and validation scripts.

## Version Rule

- Major: breaking behavior or contract change.
- Minor: new compatible capability.
- Patch: clarification, typo, or non-breaking template update.

## Deprecation Rule

Deprecated assets must record:

- replacement
- reason
- first deprecated version/date
- planned removal condition
- compatibility behavior

Do not delete a command or Skill until references are checked and a compatible entry exists.
