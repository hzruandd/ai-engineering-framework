# Frontend Review Checklist

Use when changes touch frontend pages, components, API clients, or mini-program code.

- Target stack and project conventions are identified.
- Loading, empty, error, disabled, permission, and validation states are handled.
- API contract matches OpenAPI or agreed interface.
- Sensitive fields are not displayed or logged incorrectly.
- Telemetry and manual UI acceptance items are recorded.
- Component/E2E/accessibility checks are executed or marked `NOT_EXECUTED`.
