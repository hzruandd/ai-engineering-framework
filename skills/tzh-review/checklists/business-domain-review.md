# 核心业务链路审查清单

## 触发领域

- 临停缴费
- 月租续费
- 券包核销
- 共享车位
- 发票
- 清分
- 对账
- 设备开闸
- 权限与租户隔离

## 检查项

| 检查项 | 关注点 |
|---|---|
| 业务目标是否清晰 | 是否能和 TAPD 一一对应 |
| 状态机是否闭环 | 正常流、异常流、补偿流 |
| 幂等是否存在 | 回调、重试、补单、核销、开票、开闸 |
| 金额/计费是否一致 | 计费规则、优惠、分摊、发票、清分 |
| 对账口径是否一致 | 订单、支付、清分、发票、报表 |
| 权限与隔离是否清晰 | 停车场、商户、租户、角色 |
| 失败补偿是否可执行 | MQ 重试、任务补偿、人工补单 |
| 核心日志是否足够 | traceId、bizId、订单号、停车场号 |

## 风险提醒

- 资金、计费、发票、清分、对账口径错误：`P0`
- 开闸失败导致大量用户无法出入场：`P0`
- 关键回调缺少幂等：`P0`
- 补偿链路缺失或无法验证：至少 `P1`
