# 部署与回滚审查清单

## 检查项

| 检查项 | 关注点 |
|---|---|
| 发布顺序 | 多项目、多服务是否有先后依赖 |
| 灰度策略 | 是否可逐步放量、可回看指标 |
| 配置发布 | Nacos、环境变量、密钥、白名单是否同步 |
| 数据库前滚 | DDL、DML、修复脚本是否有执行窗口 |
| 数据库回滚 | 是否有回滚脚本、兼容方案、停写策略 |
| 应急预案 | 核心链路异常时的降级、熔断、人工干预 |
| 观察期 | 发布后看哪些指标、看多久、谁负责 |

## 风险提醒

- 只有代码回滚，没有数据回滚：`P1`
- 多项目依赖顺序不清：`P1`
- 大表 DDL 无观察期与责任人：`P1`，严重可 `P0`
- 发布失败会导致核心链路不可用且无降级：`P0`
