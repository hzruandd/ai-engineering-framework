# 安全审查清单

## 检查项

| 检查项 | 关注点 |
|---|---|
| 鉴权 | 是否绕过认证、是否存在匿名高危接口 |
| 授权 | 是否存在越权访问、水平越权、垂直越权 |
| 租户隔离 | 查询、更新、缓存键、消息体是否带隔离维度 |
| 敏感信息 | 日志、接口返回、数据库脚本是否泄露手机号、车牌、身份证、支付流水号、姓名、地址、设备标识 |
| 脱敏规则 | 手机号、车牌号、身份证、支付流水号、导出报表是否按场景脱敏 |
| 加密与密钥 | 是否存在明文 `appSecret`、支付密钥、证书、token、OSS 凭证；是否使用密文配置 |
| SQL 注入 | 动态 SQL、拼接 SQL、脚本参数输入 |
| 配置安全 | 密钥、token、白名单、灰度开关、回调地址、外网域名配置 |
| 审计 | 关键操作是否有审计日志 |
| 防重与防刷 | 支付、核销、开票、开闸接口是否可重放 |
| 签名与回调 | 支付回调、Webhook、第三方通知是否校验签名、时间戳、nonce |
| 导出与下载 | 导出接口是否做权限控制、下载文件是否脱敏、是否有导出留痕 |
| 日志脱敏 | 应用日志、MQ 消息、补偿日志、异常堆栈是否输出敏感字段 |
| 文件与对象存储 | 上传下载、OSS/MinIO 链接、回单/发票附件访问是否受控 |
| 合规留痕 | 是否能说明敏感数据处理目的、范围、责任人和保留期限 |
| 敏感证据脱敏 | 评审报告、证据表、截图、日志摘录是否只保留路径、行号、字段名和掩码值 |

## 风险提醒

- 核心权限或租户隔离缺失：`P0`
- 支付、订单、发票接口可重放：`P0`
- 支付密钥、`appSecret`、证书等高敏凭证明文入库或入仓：`P0`
- 大批量敏感数据导出无权限控制或无脱敏：`P0`
- 敏感信息明文输出：至少 `P1`
- 日志、报表、消息体未脱敏：至少 `P1`
- 未说明密钥轮换、密文配置或签名校验方式：至少 `P1`
- 审计日志缺失导致追责困难：至少 `P1`
- 评审输出原样泄露完整敏感值：至少 `P1`
- 高敏凭证已入仓、进入日志、前端包或发布产物：`P0`
