# 安全审查清单

## 检查项

| 检查项 | 关注点 |
|---|---|
| 鉴权 | 是否绕过认证、是否存在匿名高危接口 |
| 授权 | 是否存在越权访问、水平越权、垂直越权 |
| 租户隔离 | 查询、更新、缓存键、消息体是否带隔离维度 |
| 敏感信息 | 日志、接口返回、数据库脚本是否泄露手机号、车牌、身份证、支付信息 |
| SQL 注入 | 动态 SQL、拼接 SQL、脚本参数输入 |
| 配置安全 | 密钥、token、白名单、灰度开关 |
| 审计 | 关键操作是否有审计日志 |
| 防重与防刷 | 支付、核销、开票、开闸接口是否可重放 |

## 风险提醒

- 核心权限或租户隔离缺失：`P0`
- 支付、订单、发票接口可重放：`P0`
- 敏感信息明文输出：至少 `P1`
- 审计日志缺失导致追责困难：至少 `P1`
