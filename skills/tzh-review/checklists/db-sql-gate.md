# 数据库与 SQL 轻门禁

## 何时必须进入数据库专项

命中以下任一信号时，先标记“数据库专项必做”，再按需加载 `db-sql-review.md`：

- 变更文件名出现 `mapper`、`repository`、`dao`、`sql`、`ddl`、`dml`
- 变更涉及 `*.xml` SQL、迁移脚本、修复脚本
- 变更涉及字段、索引、表结构
- 变更涉及 Doris、Dinky、MV、报表口径
- 变更涉及订单、支付、计费、月租、券包、发票、清分、对账、开闸核心数据读写

## 轻门禁检查项

| 检查项 | 是 / 否 | 命中后动作 |
|---|---|---|
| 涉及 SQL 查询或写入 |  | 加载深度 SQL 清单 |
| 涉及字段新增/删除/改名/类型变更 |  | 加载字段兼容性检查 |
| 涉及索引新增/删除/调整 |  | 加载索引设计检查 |
| 涉及 DDL / DML / 修复脚本 |  | 加载上线回滚与幂等检查 |
| 涉及 Doris / Dinky / MV / 报表口径 |  | 加载同步与口径检查 |
| 涉及核心账务或出入场数据 |  | 至少按 `P1` 起评估 |

## 快速判级

- 核心表 `UPDATE/DELETE` 缺精确 `WHERE`：`P0`
- 大表 DDL 无评估、无回滚、无验证 SQL：`P0`
- 金额、清分、对账、发票口径变更无验证：`P0`
- 核心 SQL 无 EXPLAIN：`P1`
- 字段兼容性不清楚：`P1`
- 修复脚本不可重复执行：`P1`

## 使用策略

- 未命中门禁：不要默认加载 `db-sql-review.md`
- 已命中门禁：再加载 `db-sql-review.md` 做详细评审
- 生成正式报告第 `9` 章时，只展开与本次命中项相关的小节
