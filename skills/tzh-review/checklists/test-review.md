# 测试与验证审查清单

## 检查项

| 检查项 | 关注点 |
|---|---|
| TAPD 是否有必测场景 | 每个 TAPD 至少对应主流程和异常流程 |
| 单元测试 | 是否覆盖核心分支、异常分支、边界条件 |
| 集成测试 | 是否覆盖跨服务调用、MQ、任务、数据库 |
| SQL 验证 | 是否提供验证 SQL、EXPLAIN |
| 回归范围 | 是否明确影响到的上下游 |
| 压测 / 性能验证 | 核心链路是否有性能依据 |
| 灰度验证 | 是否有灰度观察指标 |
| 权限与隔离验证 | 服务商、车场、租户、角色是否有反向越权用例 |
| 安全回归 | 脱敏、签名、防重放、导出权限是否有验证 |
| 缺失项是否标记 Unknown | 未提供覆盖率、测试报告时不可写“达标” |

## 停智慧核心业务测试矩阵

| 业务域 | 必测场景 |
|---|---|
| 临停缴费 | 正常支付、重复支付、支付成功回调延迟、订单关闭后回调 |
| 月租续费 | 连续续费、跨月、跨年、折扣套餐、退款 |
| 券包 | 购买、核销、过期、退款、部分核销退款 |
| 开闸 | 支付后开闸、超时、重复开闸、设备离线 |
| 发票 | 开票成功、开票失败、红冲、金额不一致 |
| 清分 | 多方分账、服务商分润、退款冲正 |
| 对账 | 渠道账单差异、平台订单差异、补单 |
| 权限与隔离 | 服务商只能看自己车场、车场只能看自身数据、导出范围受控 |

## 风险提醒

- 核心异常路径未覆盖：`P1`
- 只有主流程没有补偿/失败验证：`P1`
- 无性能验证却改动核心 SQL 或高并发链路：`P1`
- 权限、脱敏、防重放未纳入测试：至少 `P1`
