# 测试与验证审查清单

## 检查项

| 检查项 | 关注点 |
|---|---|
| TAPD 是否有必测场景 | 每个 TAPD 至少对应主流程和异常流程 |
| 单元测试 | 是否覆盖核心分支、异常分支、边界条件 |
| 集成测试 | 是否覆盖跨服务调用、MQ、任务、数据库 |
| SQL 验证 | 是否提供验证 SQL、EXPLAIN |
| 回归范围 | 是否明确影响到的上下游 |
| 压测 / 性能验证 | 核心链路是否有性能依据 |
| 灰度验证 | 是否有灰度观察指标 |
| 缺失项是否标记 Unknown | 未提供覆盖率、测试报告时不可写“达标” |

## 风险提醒

- 核心异常路径未覆盖：`P1`
- 只有主流程没有补偿/失败验证：`P1`
- 无性能验证却改动核心 SQL 或高并发链路：`P1`
