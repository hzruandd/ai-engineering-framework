## 附录 A：缺陷等级定义

| 等级 | 定义 | 典型场景 |
|---|---|---|
| P0 | 严重阻塞上线或导致核心业务/资金/数据错误 | 错账、重复扣款、核心表高危 DML、开闸不可用 |
| P1 | 高风险，需在放行前明确闭环或设条件 | 核心 SQL 无 EXPLAIN、兼容性不明、无数据回滚 |
| P2 | 中低风险优化项，建议跟踪整改 | 可维护性、观测性、部分异常路径不足 |
| P3 | 轻微优化建议 | 注释、命名、轻微重复代码 |
