# 正式评审报告结构示例

```markdown
# 智慧停车生态 · 代码评审报告

| 项目 | 内容 |
|------|------|

## 目录
## 1. 评审概述
## 2. TAPD 变更追踪矩阵
## 3. 多项目联合评审范围
## 4. 文件变更清单
## 5. 系统背景与关键链路
## 6. 设计与实现评审
## 7. 代码质量审查
## 8. 逻辑正确性与业务一致性验证
## 9. 数据库与 SQL 专项评审
## 10. 性能影响评估
## 11. 安全性审查
## 12. 日志与可观测性
## 13. 测试建议与验证计划
## 14. 风险矩阵与评审决议
## 15. 亮点总结
## 16. 待改进项
## 附录 A：证据表
## 附录 B：评分细则
## 附录 C：Unknowns 与人工确认项
## 附录 D：代码变更与 TAPD 反向追踪表
```

## 最低输出要求

- 必须保持固定主标题、封面信息表、目录、一级章节顺序
- 必须有 TAPD 正向追踪矩阵
- 必须有反向追踪表
- 必须有数据库与 SQL 专项章节
- 必须有风险矩阵与待改进项
- 必须有 Unknowns 与人工确认项
- 不得预填“通过”
