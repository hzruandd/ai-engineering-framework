### 用例5：重复用户名测试

**测试类型**：异常
**预期结果**：插入失败，返回用户名已存在错误

**请求信息**：
- **URL**：`http://localhost:9220/test/user/insert`
- **Method**：`POST`

**请求参数**：
```json
{
  "username": "test_user_001",
  "email": "test005@example.com",
  "phone": "13800138004",
  "age": 25,
  "status": 1
}
```

**响应结果**：
- **HTTP 状态码**：200
- **响应时间**：80ms
- **响应体**：
  ```json
  {
    "code": 500,
    "message": "用户名已存在",
    "data": null
  }
  ```

**验证结果**：❌ 失败
- ✅ HTTP 状态码：200
- ❌ 业务状态码：期望 500，实际 200
- ❌ 错误信息：期望"用户名已存在"，实际"操作成功"

**失败原因**：
数据库中不存在重复的用户名，导致插入成功。可能是测试数据未正确准备，或者数据库已被清理。

**建议**：
1. 在测试前先插入一条相同用户名的记录
2. 或者修改测试用例，使用已知存在的用户名
