# Test Plan Artifact Contract

Producer: `generate-tests`, `prd-authoring`, tester
Consumers: `self-test`, `tzh-review`, Test Gate
Default path: `docs/deliveries/<requirement-id>/test-plan.md`

Required fields:

- requirement_id
- tapd_id
- branch
- acceptance_criteria_mapping
- unit_tests
- integration_tests
- contract_tests
- bff_tests
- frontend_tests
- e2e_tests
- regression_scope
- test_data
- environment
- not_executed
- unknowns
