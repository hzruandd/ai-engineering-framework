# Task Artifact Contract

Producer: `pre-coding-check` or `deliver-requirement`
Consumers: coding Skills, test Skills, Gate checks
Default path: `docs/deliveries/<requirement-id>/tasks.md`

Required fields:

- requirement_id
- tapd_id
- branch
- source_prd
- source_design
- task_id
- task_type
- target_module
- target_files
- inputs
- outputs
- validation
- dependencies
- unknowns
- blockers
