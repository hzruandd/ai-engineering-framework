# 代码修改最佳实践

## 修改前必做

1. **阅读对应的业务文档**，理解完整业务流程
2. **使用 Grep 搜索相关代码**，查找所有影响点
3. **检查 Redis 缓存依赖关系**
4. **查看配置项和开关**

## 修改时注意

1. **保持事务一致性** - 数据库操作要么全成功要么全失败
2. **同步更新缓存** - 修改数据库后同步更新 Redis
3. **发送必要的消息通知** - MQ、Socket、推送等
4. **添加关键日志** - 方便排查问题

## 修改后验证

1. **单元测试** - 覆盖主要场景
2. **集成测试** - 验证完整流程
3. **边界测试** - 测试极端情况
4. **性能测试** - 多位多车等复杂场景

## 常见错误和解决方案

### 错误1: NullPointerException

```java
// 错误写法
parkingList.getInTime().getTime();

// 正确写法
if (parkingList.getInTime() != null) {
    parkingList.getInTime().getTime();
}
```

### 错误2: 并发更新丢失

```java
// 错误: 直接更新
parkingList.setShouldAmount(amount);
parkingListMapper.updateByPrimaryKeySelective(parkingList);

// 正确: 使用乐观锁或分布式锁
String lockKey = "LOCK:PARKING_LIST:" + parkingList.getId();
if (redissonUtil.tryLock(lockKey, 5, TimeUnit.SECONDS)) {
    try {
        parkingList = parkingListMapper.selectById(parkingList.getId());
        parkingList.setShouldAmount(amount);
        parkingListMapper.updateByPrimaryKeySelective(parkingList);
    } finally {
        redissonUtil.unlock(lockKey);
    }
}
```

### 错误3: 金额精度丢失

```java
// 错误: 使用float或double
float amount = 10.1f;

// 正确: 使用BigDecimal
BigDecimal amount = new BigDecimal("10.1");
```
